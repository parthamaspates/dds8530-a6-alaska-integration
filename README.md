# Big Data Integration on the Alaska Benchmark

DDS-8530 Big Data Integration, Assignment 6 (Sina Zareian, National University)

This project integrates the **Alaska benchmark** (Crescenzi et al., 2021): 69,616 heterogeneous product specifications (cameras, monitors, notebooks) from 68 e-commerce websites, with entity-resolution and schema-matching ground truth. To make the integration problem realistic, each vertical is stored in a different system and three websites arrive later as a live feed.

```
                      ┌─ camera   → PostgreSQL (EAV tables) ── SQLAlchemy ─┐
Alaska JSON lake ─────┼─ monitor  → MongoDB (documents) ────── PyMongo ────┼─► unified long table ─► cleaning (Pandas/Dask)
(Pandas│Dask│Spark)   └─ notebook → CSV partner feed ───────── Pandas/Dask ─┘          │
                                                                                         ├─► schema matching ─► unified schema
3 held-out sites ─► listing REST API ─► producer ─► Kafka ─► Spark Structured Streaming  └─► entity resolution (Pandas | Spark)
                                                             │  real-time matching against the entity catalog
                                                             └─► Parquet + MongoDB (stream_integrated) + windowed metrics
```

## Layout

| Path | Purpose |
|---|---|
| `src/alaska_int/config.py` | Settings (all overridable by environment variables), source-to-store assignment, streamed sources |
| `src/alaska_int/loaders.py` | Ingestion of the JSON lake three ways: plain Python + Pandas, Dask bag, Spark `wholeTextFiles` RDD |
| `src/alaska_int/stores.py` | Seeds PostgreSQL / MongoDB / CSV and reads them back (SQLAlchemy, PyMongo, Pandas, Dask) |
| `src/alaska_int/clean.py` | Missing values, duplicate attributes and listings, text repair, unit normalization (inches, kg), brand canonicalization |
| `src/alaska_int/schema_match.py` | Unsupervised name-based schema matching (RapidFuzz) and evaluation against the ground truth |
| `src/alaska_int/er.py` | Entity resolution (brand + model-code blocking) in Pandas and in Spark DataFrames; pairwise evaluation |
| `src/alaska_int/feed_api.py` | FastAPI listing feed that releases the held-out sites in real time |
| `src/alaska_int/producer.py` | Polls the API and publishes listings to Kafka |
| `src/alaska_int/stream_job.py` | Spark Structured Streaming: Kafka → parse → real-time entity matching → Parquet + MongoDB, windowed counts |
| `src/alaska_int/viz.py` | Matplotlib/Seaborn figures |
| `notebooks/A6_Alaska_Integration.ipynb` | The executed analysis (generated by `scripts/build_notebook.py`) |
| `outputs/` | Figures, `metrics.json`, HTML export of the notebook, logs, test results |
| `tests/` | Unit tests for parsers, cleaning, schema matching and entity resolution |

## Run everything (Docker Desktop, 8 GB memory or more)

```bash
docker compose build
docker compose run --rm app        # starts PostgreSQL, MongoDB, Kafka and the feed API, then runs scripts/run_all.sh
docker compose down
```

`run_all.sh` downloads the data from the Alaska GitHub repository, runs the tests, executes the notebook and exports it to `outputs/A6_Alaska_Integration.html`. It takes roughly 10 minutes on a laptop.

## Results (Docker on a 10-core MacBook; `outputs/metrics.json`)

| | Camera | Monitor | Notebook |
|---|---|---|---|
| Schema matching precision / recall / F1 | .82 / .51 / .63 | .72 / .36 / .48 | .77 / .24 / .37 |
| Entity resolution precision / recall / F1 | .90 / .67 / .77 | .27 / .31 / .29 | .24 / .73 / .36 |

* Cleaning: 6,991 placeholder values, 326 duplicate attributes and 1,946 duplicate listings removed (65,154 listings kept).
* Completeness of the unified schema: missing brand 61% -> 13%, screen size 58% -> 38%, weight 75% -> 65%.
* Spark and Pandas entity resolution agree on 100% of listings.
* Streaming: 2,516 listings through Kafka in 21 micro-batches (114 s, ~22 listings/s); 73% matched to a known entity in real time, 86% of those correct on labeled listings; maximum end-to-end lag 6.5 s.
* Timings (s): ingest Pandas 34.5 / Dask 19.6 / Spark 28.8; clean Pandas 9.5 / Dask 6.0; join Pandas 0.5 / Dask 1.3 / Spark 2.5; entity resolution Pandas 2.7 / Spark 12.2.
